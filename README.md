# Ozinshe Coffee

Сайт кофейни в Жезказгане на русском и казахском языках.

[Открыть сайт](https://rahatburiev-create.github.io/ozinshe-coffee/)

## Файлы

- `index.html` — страница, контакты и сведения о кофейне.
- `style.css` — оформление для телефона и компьютера.
- `app.js` — меню, языки, навигация и галерея.
- `assets/` — изображения и значок сайта.

Сайт работает без сборки и базы данных. Для локального просмотра откройте `index.html` в браузере. В исходном проекте основные файлы находятся в папке `dist/`.

## GitHub Pages

Файлы сайта размещаются в корне репозитория. В **Settings → Pages** выберите **Deploy from a branch → main → /(root)**. Файл `.nojekyll` должен оставаться в корне.
