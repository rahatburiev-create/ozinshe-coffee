# Ozinshe Coffee

Адаптивный сайт кофейни в Жезказгане на русском и казахском языках.

## Запуск

Откройте `index.html` в браузере. Установка программ, сборка и база данных не нужны.

## Публикация GitHub Pages

1. Загрузите все файлы в корень репозитория вместе с папкой `assets`.
2. Откройте **Settings → Pages**.
3. Выберите **Deploy from a branch → main → /(root) → Save**.

## Содержимое

- `index.html` — страница и контактные данные.
- `style.css` — оформление для телефона и компьютера.
- `app.js` — переключение языков, меню с ценами, навигация и галерея.
- `assets/` — пять новых изображений и значок сайта.

Цены находятся в массиве `menu` в `app.js`. Изображения созданы с помощью ИИ для оформления, передают стиль кофейни и не являются документальными фотографиями заведения. Старые снимки в эту версию не включены.
